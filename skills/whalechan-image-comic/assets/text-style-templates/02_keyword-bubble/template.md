# Keyword bubble

![Reference](reference.webp)

- Use for excuses, spin, false reassurance, or a setup that hides an embarrassing payoff.
- Use one large organic speech bubble containing 3–5 lines in a clear reading order.
- Set the setup in smaller dark navy; enlarge the promise or reveal; color at most two keywords bright blue or warning red.
- Permit one hand-drawn underline and a few sweat drops. Keep the bubble tail unambiguous.
- Put every semantic line in `core_text`; reserve only nonverbal accents for `flavor_text`.
- Do not give every line equal size or add unrelated text outside the bubble.

Prompt fragment: Use one large organic comic bubble with strong internal hierarchy: small dark setup, oversized bold claim, one blue keyword, one red payoff keyword, and a loose yellow underline. Copy only the hierarchy and visual treatment, not the reference wording.
