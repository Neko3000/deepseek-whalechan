# Shy blue sticker

![Reference](reference.webp)

- Use for bashful refusal, pleading, flustered denial, or cute protest.
- Stack 3–5 short lines beside the character; allow the block to occupy 30–45% of the canvas.
- Use chunky rounded deep-blue lettering, a thick white sticker outline, and a pale-blue offset shadow.
- Keep line lengths uneven and slightly tilted. Add only a few blue hearts, drops, waves, or one tiny pictogram.
- Put one concise `core_text` statement in the large block. Treat symbols as `flavor_text`.
- Keep the character readable; do not turn the layout into a centered corporate headline.
