# Burst command

![Reference](reference.webp)

- Use for anger, prohibition, accusation, orders, or sudden exposure.
- Put a compact one- or two-line statement inside a jagged burst frame near the top.
- Use dense, very heavy black hand-drawn lettering with white separation from the frame.
- Allow pink anger marks or tiny subject pictograms only when they clarify tone.
- Keep the command or accusation in `core_text`; use anger marks as `flavor_text`.
- Do not use for timid, affectionate, or low-energy scenes.

Prompt fragment: Put the core wording inside a bold jagged manga burst: dense heavy black hand-lettered Chinese, tight two-line packing, strong white separation, irregular energetic contours, and two restrained anger accents. Do not copy the reference sentence or icons.
