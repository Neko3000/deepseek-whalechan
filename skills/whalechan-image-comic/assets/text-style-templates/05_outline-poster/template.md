# Outline poster

![Reference](reference.webp)

- Use for identity claims, shameless boasts, slogans, or one-sentence punchlines.
- Place a two-line declaration across the top 30–45% of a single panel.
- Use white-filled rounded letters, an extremely thick near-black outline, and a deep-blue offset extrusion.
- Make one line or phrase dominant; add paired blue emphasis rays only.
- Put the full declaration in `core_text`; omit helper copy by default.
- Do not shrink it into a normal speech bubble or add a detailed backdrop behind the letters.
